# Ahmed Arfaoui — Portfolio

This is the source code for my personal portfolio.

I did not want to build another portfolio that only lists technologies and
project names. I wanted this one to show how I think, what I have worked on,
and the road that brought me here.

Formula 1 is a big part of the design because it is where my interest in data
really started. I was fascinated by how much information sits behind every lap,
decision, and result. Photography is the other side of the site. It is how I
slow down, notice details, and keep moments that matter to me.

## What is inside

- **Home** — a quick introduction, selected work, skills, and contact links.
- **Projects** — the AI, data science, computer vision, MLOps, and browser-agent
  projects I have built.
- **Experience** — what I worked on and learned during each internship.
- **Journey** — my years at IPEIB, the difficult moments, my move to ESPRIT,
  and finally graduating with an excellent mention.
- **Photography** — a collection of photographs I took around Tunisia.
- **For Dad** — a personal page about my father and what his strength taught
  me.

Some parts of this portfolio are professional and some are very personal. That
is intentional. The failures, the people around me, and the difficult years are
as much a part of my story as the final degree or the finished projects.

## Running it locally

You need Node.js 22 or newer.

```bash
npm ci
npm run dev
```

The local site will be available at `http://localhost:3000`.

To run the build and content checks:

```bash
npm test
```

## GitHub Pages

The repository includes a GitHub Actions workflow for deployment. After GitHub
Pages is configured to use **GitHub Actions**, every push to `main` builds and
publishes the latest version.

The expected address is:

`https://arfaouiahmed1.github.io/Ahmed-Arfaoui-Portfolio/`

One important note before publishing: the site includes family photographs, a
graduation video, and the story of my father's illness. Once GitHub Pages is
enabled, those files become public. I want that decision to be made
deliberately.

## Security and privacy

I kept the site static on purpose. There is no database, login, contact form,
tracking, advertising, or third-party JavaScript. The hosted version also uses
browser security policies, and the GitHub Pages version is exported without
runtime JavaScript.

If you find a security issue, please read [SECURITY.md](SECURITY.md) and contact
me privately.
