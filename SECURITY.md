# Security policy

## Supported version

Security fixes are applied to the latest version on the `main` branch and to
the currently published portfolio.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
`ahmedarfaoui2000@gmail.com`. Include the affected URL, reproduction steps,
impact, and any supporting screenshots. Please do not disclose an unresolved
issue publicly or access, modify, or retain another person's data while testing.

## Security and privacy model

This portfolio is intentionally static. It has no application login, database,
contact form, analytics, advertising, cookies, or third-party JavaScript.
Browser policies restrict executable and embeddable content, external links
opened in new tabs are isolated from the portfolio, and the deployment workflow
uses job-level least-privilege permissions.

The site contains personal photographs, a graduation video, and a family
memorial. These files are public if GitHub Pages is enabled. They should never
contain hidden credentials, private documents, location metadata, or other
secrets.
